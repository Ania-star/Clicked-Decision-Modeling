# 🏎️ Monaco Grand Prix 2024 Winner Prediction Model
This repository contains my prediction modeling project, developed as part of a 4-week Data Modeling journey. The aim was to predict the winner of the Monaco Grand Prix 2024 by applying data analysis and machine learning techniques to historical Formula 1 datasets. The project was developed using Google Colab

## 🏁 Project Summary
This project involves exploratory data analysis (EDA), feature engineering, and training a Random Forest Classifier to predict the winner of the Monaco Grand Prix 2024. Emphasis was placed on improving model accuracy, handling data imbalance, and refining model performance through hyperparameter tuning.
